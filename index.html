How the network works

  1. Watch. The Sentinel reactive contract on Lasna subscribes to Transfer events of the WETH contract on Base Sepolia (0x4200000000000000000000000000000000000006).
  2. Decide on-chain. A transfer at or above the threshold (0.05 ETH, stored immutably in the contract) increments largeSellCount and records the amount and block.
  3. Alert cross-chain. The Reactive Network delivers a callback to SentinelCallback on Base Sepolia, which stores the alert count, amount, and block.
  4. Explain. This site's agent network reads that public state in your browser and explains it — counts, amounts, threshold ratios, and whether the watch → alert loop is intact.

The loop has already fired end-to-end on testnet with a real, organic transfer: one large transfer flagged, one alert received, matching amounts. The panel above reads the contracts directly, so you can verify every number yourself.

Your key stays in this browser (localStorage for this origin only) and is never sent to this site, the manifest, or any peer — exactly as the agentic web specification requires.

    Files for agents and runtimes

    This site conforms to the Minimum Viable Specification for a Worldwide Agentic Web (MVP Profile 0.2, Cognizant AI Lab). Another agent site can call this network by taking this page's folder URL, appending the network name (sentinel_watchdog), and loading the manifest from that base.

    FileWhat it is
    agent-manifest.json Machine-readable index of this site: the published network (name, front agent, network file), router metadata, and peer policy. Public GET, CORS-enabled when hosted.
    sentinel_watchdog.network.json The agent network definition (Neuro SAN data model, JSON serialisation): agents, their functions, instructions, tools, and site actions.
    runtime.js The runtime file: a dependency-free browser runtime that loads the manifest and network, validates them, and runs the front agent with bounded steps.
    runtime.json Runtime descriptor: exact conformance subset, assumptions, and what is planned next.
    links.json Peer-network link map. No peers are bound yet — the watchdog currently calls only its own agents.
    agent-mcp.json MCP facade status: explicitly unavailable on static hosting (see the file for why, and how agents interact instead).
